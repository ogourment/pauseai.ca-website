# Contributing

Thank you for helping make difficult AI-risk questions understandable in
English and French.

## Development

1. Install the versions listed in `README.md`.
2. Run `mix setup`.
3. Create a focused branch.
4. Add tests for the behavior being introduced.
5. Run `mix precommit`.
6. Open a pull request explaining the visitor-facing change.

No AI assistant, agent configuration, or proprietary development tool is
required. Do not commit `AGENTS.md` or `CLAUDE.md`.

## Editorial changes

For a source or summary, include its canonical URL, author/publisher, original
language, and factual review date. Do not copy or translate third-party work
unless its license or explicit permission allows it.

Keep uncertainty and serious objections visible. English and French versions
both require human review.

## Personal data

Do not add new personal-data collection, trackers, public activity, or
visibility defaults without a documented privacy and security review.
